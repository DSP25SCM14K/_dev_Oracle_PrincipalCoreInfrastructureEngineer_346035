# Dev Kumar — Core Infrastructure Portfolio

A responsive portfolio highlighting distributed systems, cloud infrastructure, hardware-fleet orchestration, operational reliability, and selected engineering projects.

## Files

- `index.html` — complete static portfolio page
- `styles.css` — responsive styles, visual system, motion, and reduced-motion support
- `script.js` — animated background topology, rotating focus text, reveal effects, and project search
- `ROLE_RESEARCH.md` — Oracle/OCI role research and resume-to-role evidence map

## Publish with GitHub Pages

The site is static and has no build step. In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. GitHub Pages will serve `index.html` from the repository root.

## Accessibility and motion

The background canvas is decorative. The page includes semantic sections, accessible labels, keyboard-operable links and search, and reduced-motion handling for the ambient background.
